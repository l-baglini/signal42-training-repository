# SetLog

A phone-friendly workout log & recap app — no accounts, no cloud, just you,
your lifts, and a chart of whether you're progressing.

See [`SPEC.md`](./SPEC.md) for the full design, [`CLAUDE.md`](./CLAUDE.md)
for working conventions and challenge context.

## Run it

No build step, no dependencies. Just open `index.html` in a browser.

```bash
open index.html       # macOS
xdg-open index.html   # Linux
```

## Status

All four screens (Today, History, Progress, Settings) implemented per
`SPEC.md`. Not yet reviewed by the user — that pass is still to do before
this counts as "done" (see `CLAUDE.md`).
